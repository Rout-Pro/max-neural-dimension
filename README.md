# MAX - Neural Dimension

Native Android AI companion (Kotlin + Jetpack Compose, minSdk 26). Purple liquid-glass design with a real-time 3D humanoid robot, live voice conversation and streaming AI chat through a secure backend.

This project implements the "MAX 2.0 - Neural Dimension" master blueprint (25 parts) in phases, keeping the project compilable at every milestone.

## Phase 1 (current, v2.0)

Working and verified on an emulator (Pixel 6, API 34):

- **Rigged 3D character asset** - `app/src/main/assets/max_robot.glb` is a real glTF 2.0 binary asset generated by `tools/export_robot_glb.py`: named node rig (head, face, eyes, mouth, ears, torso, shoulders, ring, core) with morph targets ("mouthOpen", "blink") driven at runtime.
- **Custom OpenGL ES 3.0 renderer** (blueprint allows "Filament or equivalent 3D renderer") with a GLB loader: PBR-ish lighting, emissive glow, glass faceplate, particle field, additive glows.
- **Animation state machine** - IDLE / LISTENING / THINKING / SPEAKING / HAPPY / CURIOUS / CONFUSED / EXCITED / ERROR driven by real app events.
- **Lip-synced voice** - Android TTS is synthesized to a WAV file, its measured amplitude envelope drives the mouth morph during MediaPlayer playback.
- **Live voice conversation** - SpeechRecognizer (partial + final results), interrupt, continuous mode, languages (en-IN / en-US / hi-IN), speech-rate control.
- **Streaming AI chat via secure backend** - provider keys (Gemini / OpenAI-compatible / Groq) live server-side only (blueprint Part 11); backend source in `backend/` (Cloudflare Worker), deploy steps in `backend/README.md`.
- **Chat history** - Room database, multiple conversations, delete, copy, markdown + code rendering.
- **Holographic panels** - floating glass panels (AI status, tasks, alerts, today, actions, memory) fed by real app data.
- **Tasks + memory** - Room-backed tasks; on-device memory facts (user-controlled, sent as chat context).
- **Device tools** - flashlight, battery, storage, volume, Wi-Fi/Bluetooth shortcuts.
- **Settings** - profile, secure backend, Fast/Thinking mode, personality, voice, robot animation, reduced motion, memory.

## Honest gaps / later phases

- **Backend hosting is not deployed yet** - it needs the user's own free hosting account (options in `backend/README.md`). Until the URL is set, the app shows an honest "secure backend not connected" state instead of fake replies.
- Speech recognition needs Google speech services on the device; TTS voices depend on the installed engine.
- Phase 2: reminders/notifications (WorkManager), security lock (PIN/biometric), wake word, extended Room entities (Part 22), notes.
- Phase 3: web development studio (Part 15), creative studio (Part 16, needs provider APIs), deep research, performance tiers (Part 23).

## Build

GitHub Actions builds and signs the APK with the persistent release key (ND_* repo secrets), so updates install in place.

- Build + sign: `.github/workflows/android.yml`
- Emulator UI verification with screenshots: `.github/workflows/ui-screenshot.yml` (`tools/drive_ui.py`)
- Regenerate the character asset: `python3 tools/export_robot_glb.py`
